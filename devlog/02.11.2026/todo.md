## Перевірена поведінка

### Error та доменні винятки

- [x] `Error`: збереження коду, повідомлення та категорії; відхилення порожнього коду, порожнього повідомлення й невизначених значень `ErrorType`.
- [x] `BaseException`: збереження коду, категорії, повідомлення, контексту та початкового винятку.
- [x] Перевірено порожній контекст за відсутності аргументу, незалежність контекстів різних екземплярів і збереження переданих посилань.
- [x] Для фабрик `DomainDataInconsistencyException`, `DomainInvalidOperationException` та `DomainInvariantViolationException` перевірено діагностичні коди, категорії, стандартні й передані повідомлення, контекст та `InnerException`.
- [x] Перевірено операцію за замовчуванням, явно передані операції, тип доменного об’єкта та додаткові діагностичні дані.

### DomainGuard

- [x] `AgainstNull`: відсутність полів, допустимі ненульові значення, кілька полів, перше некоректне поле та nullable-значення.
- [x] `AgainstEarlierThan`: час раніше, пізніше та рівний мінімуму; порушення межі на один tick.
- [x] Для дат перевірено однаковий момент із різними UTC-зсувами та випадки, коли порядок локального часу відрізняється від порядку реальних моментів.
- [x] `AgainstUndefinedEnum`: визначені й невизначені значення різних enum, кілька аргументів та перше некоректне поле.
- [x] У винятках перевірено код, категорію, назви полів, тип власника, операцію та відповідні діагностичні значення.

### Базові моделі

- [x] `Entity`: ініціалізація ID та часу створення, поточний UTC-час за відсутності дати й початковий стан колекцій подій та змін.
- [x] Перевірено `Equals(object)`, типізований `Equals`, оператори `==` і `!=`, узгодженість хеш-кодів.

- [x] Звірено `AggregateRoot` і `AggregateRootId` як базові класи без додаткової власної поведінки; `AggregateChange` і `DomainEvent` — як контейнери переданого часу.
